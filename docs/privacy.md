# Veeky 隐私说明（独立插件版本）

更新：2026-10-27。

Veeky 在用户请求时读取视频标题、链接、时长和字幕，用于字幕翻译和摘要。X 实验功能在本机获取媒体并运行语音识别。正常分析不使用 Veeky 自建服务器。

字幕文本会发送至用户选择的官方 LLM 服务商（Kimi、DeepSeek、腾讯混元、通义千问或智谱 GLM），用于生成译文和摘要。该服务商依其政策处理请求和账户信息；费用由用户账户承担。插件仅将 API Key 发送给相应官方 API，不提供给 YouTube 或 X 网页。

Key 默认只保留在当前浏览器会话。用户选择“记住在此设备”后保存在本机扩展存储，不使用 Chrome 同步；取消选中并保存可移除该服务商已记住的 Key。旧版本的配置隔离保留，不自动复用。

分析结果和历史保存在本机 IndexedDB，不自动同步。卸载扩展、清理扩展数据或浏览器数据可能使记录丢失。任务会保存已完成的文本步骤以支持继续执行，不将签名媒体地址或音频字节写入历史。

历史页可查看存储用量并确认删除单条已完成记录及其任务数据；暂停或失败的任务可以选择放弃并删除本机文本进度。不会自动删除已有历史；任务完成后清理重复的临时文本检查点，完整结果保留。

X 模型首次使用时从 Hugging Face 下载并缓存，模型站及其 CDN 会接收必要的网络请求信息。模型缓存不包含用户音频。视频平台也会接收插件读取字幕/媒体时的网络请求。

用户可主动从原本地服务导入历史。此时插件临时请求本地访问权限，使用原安装身份只读获取已完成记录；不删除原服务数据，结束后撤销临时访问权限。常规分析不会访问原服务。

本项目不在本次实现中添加广告、行为分析或遥测上报。发布商店前应补充发布者联系方式、公开政策页面，并核对实际发布包的数据行为与本说明一致。
