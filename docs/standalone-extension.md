# Veeky 独立插件实施说明

更新：2026-10-28。开发版和发布候选均不需要 Veeky 分析服务器、API 域名或 Docker。

## 数据流

- YouTube：扩展读取当前页面的播放器元信息与可访问字幕轨道，获取带时间戳的字幕；粘贴另一个链接时可临时打开后台标签页读取元信息。无可读取字幕时给出错误，不自动使用语音识别。
- LLM：浏览器后台从可信存储取出所选官方服务商的 Key，直接请求官方 HTTPS 接口。分段翻译、结构化摘要、章节与重点结果经校验后写入本机。不会经过 Veeky 服务。
- 任务：offscreen 扩展文档管理任务，独立 Worker 执行语音识别。已完成翻译和摘要步骤持久化；每次仅一个运行任务。点击暂停后保留进度，重新打开插件后手动继续。继续任务可能产生新的模型调用费用。
- 历史：本机 IndexedDB，仅展示完整结果，重复分析产生新记录，已分析视频默认读取最近完成记录。不同浏览器配置不共享历史。
- 存储：已完成历史上限 1,000 条或 100 MiB；任务、字幕分段和摘要进度合计上限 256 MiB，单任务上限 64 MiB。达到上限会提示用户处理，不自动淘汰历史。历史页显示用量，删除记录需要确认；已暂停任务可以显式放弃并清理文本进度。完成任务后清理重复的分段检查点，保留完整结果。模型另设 1 GiB 上限，下载前检查浏览器空间。
- X：仅支持当前用户可正常播放的公开帖视频；播放后捕获媒体地址。媒体请求只允许 `video.twimg.com`，不会发送 LLM Key、X Cookie 或页面认证头。媒体地址只在内存使用，不写入历史。

## X 实验功能

默认关闭，需在设置中启用，再在分析确认页允许模型下载。固定使用 `Xenova/whisper-small`、q8、WASM CPU、单线程，无云端 ASR 或 tiny 降级。模型首次安装从官方模型元信息解析不可变提交 SHA，再固定下载并缓存；不在后续加载中自动漂移到 main。下载验证文件摘要，失败不使用不完整缓存。

模型数据从 Hugging Face 及受限官方 CDN 下载。JavaScript 和 WASM 随扩展打包，不从模型站下载执行代码。音频按 30 秒窗口解码、16kHz 单声道识别并持久化文本进度；不持久保存视频、完整 PCM 或媒体签名地址。

当前环境无法完成真实模型下载，因此真实 Whisper 初始化、完整 X 解码识别、CPU 速度/峰值内存和长视频稳定性尚未验收。实验功能不能作为已完成的实时字幕承诺，也不应在商店文案中宣称稳定支持。发布前记录目标设备、Chrome 版本、模型 SHA、视频时长、下载时长、识别时长、峰值内存、暂停/恢复结果及字幕时间偏差。

## Key 与权限

设置页将 Key 保存方式、连通测试费用和数据隐私说明统一收纳在“记住在此设备”右侧的 Lucide Info 线性图标中，不展示文字按钮。悬停预览浮层，移入浮层可继续阅读，移出后关闭；点击图标固定显示，再次点击、点击外部或按 Esc 关闭。支持 Enter/空格打开及 Tab 进入浮层阅读。浮层根据侧栏空间定位并可滚动，不挤动表单。配置控件、测试/保存反馈、迁移提醒及 X 实验风险提示仍直接显示；不改变授权、Key 保存或任务逻辑。

支持 Kimi、DeepSeek、腾讯混元、通义千问和智谱 GLM。地址由服务商注册表固定，拒绝任意代理地址和带 Key 的重定向。Key 默认存入 `chrome.storage.session`；仅用户勾选后存入本机 `chrome.storage.local`，两者都限制为可信扩展上下文访问。持久保存不等于系统钥匙串加密，本机账户的访问者仍应被视为可信。

旧 Key 保留在原存储中隔离，不自动激活、不自动删除。任务消息、IndexedDB、历史迁移数据不携带 Key。结果不向网页插入 HTML；X 字幕叠层仅使用文本。

正常运行需要对应视频、媒体、模型及官方 LLM 域名权限。旧本地服务只有 optional host permission；显式点击迁移时申请，用完移除。CSP 对网络目的地设白名单，对脚本限定本机打包代码与 WASM。

## 旧历史迁移

1. 保持原插件安装和原身份数据，临时启动原本地 API。
2. 历史页阅读并勾选导入说明，点击导入并授予本地访问权限。
3. 插件只读取当前安装身份的已完成列表和结果，不注册新身份、不写入或删除后端数据。
4. 比对导入、已存在、不兼容数量，抽查内容。取消/失败时已导入记录保留，再次导入会跳过它们。
5. 确认迁移后可自行停用旧服务。升级不清理原数据库。

迁移只支持原默认地址 `http://127.0.0.1:8000`，不是任意服务器导入工具。卸载插件或更换浏览器配置可能使原安装凭据不可用，届时不能冒用其他身份读取旧历史。
